# Synapse AI — Expo SDK 56

## Getting started
```bash
npm install        # already run (node_modules/ exists)
npx expo start     # dev server (press w for web, a for Android, i for iOS)
npm run ios        # native iOS dev build (requires expo-dev-client)
npm run android    # native Android dev build (requires expo-dev-client)
npm run web        # `expo start --web`
```

## Architecture
- **Entrypoint**: `package.json` `"main": "expo-router/entry"` — file-based routing in `src/app/`
- **Path aliases** (tsconfig): `@/*` → `src/*`, `@/assets/*` → `assets/*`
- **Tab navigation**: `NativeTabs` on iOS/Android (`app-tabs.tsx`), custom web tabs (`app-tabs.web.tsx`)
- **Platform variants**: `[name].web.tsx` (web), `[name].tsx` (native fallback)
- **Experiments enabled** (app.json): `typedRoutes`, `reactCompiler`

## Key commands
| Command | Action |
|---|---|
| `npm run lint` | `expo lint` (no ESLint config yet — may prompt to create one) |
| `npm run reset-project` | Moves `src/` + `scripts/` to `example/` and creates blank `src/app/` |

No tests, no typecheck script, no CI.

## Style conventions
- `.vscode/settings.json`: `source.fixAll`, `source.organizeImports`, `source.sortMembers` on save
- Light/dark theme via `@/constants/theme` (`Colors`, `Spacing`, `Fonts`, `BottomTabInset`, `MaxContentWidth`)
- `ThemedText` component with props `type` and `themeColor` for consistent typography
- CSS Modules for web-specific styles (e.g., `animated-icon.module.css`)

## Constraints
- SDK 56 — read versioned docs at https://docs.expo.dev/versions/v56.0.0/
- Uses `react-native-reanimated`, `react-native-worklets`, `expo-image`, `expo-symbols`, `@expo/ui`
- `/ios` and `/android` directories are gitignored (generated by `npx expo prebuild`)
